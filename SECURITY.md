# Security policy / Política de seguridad

**EN** - Please report vulnerabilities privately through GitHub Security Advisories ("Report a vulnerability" on the
Security tab). Do not open public issues for security problems. Supported version: the latest release.

Scope includes gate bypasses in the CLI, unsafe defaults in templates or workflows, and skill instructions that could
lead agents to unsafe actions.

**ES** - Reporta vulnerabilidades de forma privada mediante GitHub Security Advisories ("Report a vulnerability" en la
pestaña Security). No abras issues públicos sobre problemas de seguridad. Versión soportada: el último release.

El alcance incluye formas de saltarse las compuertas de la CLI, valores por defecto inseguros en plantillas o
workflows, e instrucciones de skills que puedan llevar a un agente a realizar acciones inseguras.
