# sdlc-harness

An **agent-agnostic harness for the software development lifecycle**: it gives any coding agent the same guides and the
same deterministic gates, from discovery to retirement, with controls that scale from a solo developer to a regulated
organization.

Un **arnés agnóstico al agente para el ciclo de vida del desarrollo de software**: da a cualquier agente de programación
las mismas guías y las mismas compuertas deterministas, desde el descubrimiento hasta el retiro, con controles que
escalan desde una persona sola hasta una organización regulada.

```bash
pipx install git+https://github.com/huanrasan/sdlc-harness@v0.6.0
sdlc init path/to/your-repo --profile standard      # add --adopt for an existing repository
```
